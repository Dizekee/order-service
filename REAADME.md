Сервис для обработки заказов цифровых товаров с поддержкой платежей, интеграции с поставщиками и автоматической выдачи товаров.

## 🚀 Быстрый старт

### Требования
- Docker & Docker Compose
- Make (опционально)
- Go 1.23+ (для локальной разработки)

### Запуск
```bash
# 1. Клонировать репозиторий
git clone <your-repo>
cd order-service

# 2. Создать .env файл
cp .env.example .env  # или создать вручную

# 3. Запустить через Docker Compose
make docker-up

# 4. Проверить работоспособность
curl http://localhost:8080/health
